
# Dados e Analytics

Certificações profissionais em governança de dados, gestão da informação, Business Intelligence (BI), engenharia de dados, bancos de dados, plataformas analíticas e ciência de dados.

Esta curadoria reúne certificações de diferentes instituições, organizadas por área de atuação, para ajudar você a identificar quais conhecimentos e competências são avaliados em cada uma.

**Nível:** 🟢 Iniciante · 🟡 Intermediário · 🔴 Avançado

> **Importante:** os níveis são orientativos e não representam necessariamente a classificação oficial das instituições. Algumas certificações exigem experiência profissional, conhecimentos técnicos ou outros pré-requisitos.

## Governança, gestão e qualidade de dados

### <img src="https://www.google.com/s2/favicons?domain=dama.org&amp;sz=64" width="26" height="26" align="center" alt="DAMA International"> DAMA International

A DAMA International é uma associação profissional dedicada à gestão de dados. Sua certificação CDMP (Certified Data Management Professional) utiliza como referência o DAMA-DMBOK.

| Certificação | O que avalia | Nível |
|:---|:---|:---:|
| [CDMP — Associate](https://dama.org/certification/) | Fundamentos de governança, arquitetura, qualidade, metadados, segurança e gestão de dados | 🟢 |
| [CDMP — Practitioner](https://dama.org/certification/) | Conhecimentos de gestão de dados e aprofundamento em áreas de especialização | 🟡 |
| [CDMP — Master](https://dama.org/certification/) | Domínio avançado de gestão de dados, especializações e experiência profissional | 🔴 |

**Observação:** Associate, Practitioner e Master são níveis da certificação CDMP. A progressão depende dos requisitos estabelecidos pela DAMA.

### <img src="https://www.google.com/s2/favicons?domain=edmcouncil.org&amp;sz=64" width="26" height="26" align="center" alt="EDM Council"> EDM Council

O EDM Council desenvolve frameworks e programas relacionados à governança, gestão e controle de dados corporativos.

| Framework | O que avalia | Nível |
|:---|:---|:---:|
| [DCAM — Data Management Capability Assessment Model](https://edmcouncil.org/) | Capacidades organizacionais de governança, qualidade, arquitetura e controle de dados | 🟡 |
| [CDMC — Cloud Data Management Capabilities](https://edmcouncil.org/frameworks/cdmc/) | Capacidades de governança, segurança, privacidade e gerenciamento de dados em nuvem | 🟡 |

**Observação:** DCAM e CDMC são frameworks de avaliação de capacidades. Consulte o EDM Council para identificar as credenciais profissionais disponíveis.

## Tecnologias e ferramentas complementares

Além das certificações profissionais, existem tecnologias amplamente utilizadas em projetos de Dados e Analytics.

| Tecnologia | Principal aplicação |
|:---|:---|
| [SQL](https://en.wikipedia.org/wiki/SQL) | Consulta, manipulação e análise de dados relacionais |
| [Python](https://www.python.org/) | Automação, análise de dados, engenharia de dados e ciência de dados |
| [R](https://www.r-project.org/) | Análise estatística, visualização e modelagem de dados |
| [Excel](https://www.microsoft.com/microsoft-365/excel) | Análise, tratamento, cálculos e visualização de dados |
| [Apache Spark](https://spark.apache.org/) | Processamento distribuído de grandes volumes de dados |
| [Apache Airflow](https://airflow.apache.org/) | Orquestração e agendamento de pipelines de dados |
| [Apache Kafka](https://kafka.apache.org/) | Transmissão e processamento de eventos em tempo real |
| [PostgreSQL](https://www.postgresql.org/) | Banco de dados relacional de código aberto |
| [MySQL](https://www.mysql.com/) | Banco de dados relacional |
| [SQL Server](https://www.microsoft.com/sql-server) | Banco de dados relacional e soluções corporativas |

**Observação:** esta seção apresenta tecnologias, não certificações. O domínio de uma ferramenta não implica a existência de um exame oficial correspondente.

## Sobre esta curadoria

- **Nível:** classificação orientativa de dificuldade, não necessariamente o nível oficial da instituição.
- **O que avalia:** resumo dos principais conhecimentos e competências associados à certificação.
- **Links:** direcionam às páginas de certificações ou aos catálogos oficiais.
- **Pré-requisitos:** algumas certificações exigem experiência profissional, conhecimentos técnicos ou outros requisitos específicos.
- **Escopo:** prioriza certificações profissionais. Frameworks, acreditações e tecnologias complementares são identificados separadamente.
- **Instituições:** alguns provedores possuem catálogos amplos ou variáveis e, nesses casos, são apresentados por meio de links para consulta oficial.
